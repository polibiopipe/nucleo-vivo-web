Procesar factura PDF

Subir factura
PDF de hasta 3 MB. Primero se analiza; el stock solo cambia después de aprobar.

Reglas del flujo

  1. El PDF se interpreta y extrae folio, contraparte y líneas.
  2. Se intenta relacionar cada línea con un SKU existente.
  3. Los productos desconocidos quedan marcados para revisión.
  4. Solo al aprobar se crea el documento y el movimiento de stock.
  5. Una misma factura no debe procesarse dos veces.
